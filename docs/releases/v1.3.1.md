# v1.3.1 - Wait for the paired Node-RED bridge before Hub startup

The 2026-10-11 boot trace showed Hub and Node-RED starting together: Node-RED was
active but its HTTP bridge refused the first DRAIN requests. Hub correctly
latched startup_drain_failed. This patch adds a real paired-v2 DRAIN readiness
check before the Hub process starts, retaining the Hub's own startup DRAIN and
fault inhibition.

Only connection refusal is retried in a 60-second retry/acceptance window.
Requests use a 3-second socket inactivity timeout; the systemd startup limit is
75 seconds. Late receipts are rejected. Malformed receipts and other transport
failures fail the invocation; existing Restart=on-failure can retry the service.
No fault is cleared, no SUPPLY is sent, and no weather/settings policy changes.

The trusted-console updater in deployment/startup-readiness requires exactly
installed 1.3.0, 24 V disconnected and durable USER_OFF/DRAIN. It makes verified
software and SQLite/identity backups and adds a root-owned systemd drop-in.
Existing units/configuration and source checkout are preserved. Failure after
stop leaves Hub stopped and requests DRAIN; there is no automatic rollback.

Validation: 685 tests passed, Ruff, strict mypy (27 files), diff whitespace check.
Independent review findings on baseline and timing semantics were resolved.
Build artifacts and exact source/hash identities are supplied separately.

Deployment of the exact 1.3.1 wheel is confirmed by the operator receipt.
A cold boot with delayed Node-RED remains untested. The
installed history 1.3.0 and Dial v1.3.0-shower.3 evidence is recorded in
[the installation record](../evidence/2026-10-11-shower-history-install.md).
No physical valve position, energized test or power-loss acceptance is claimed.

Published on explicit operator request on 2026-10-11. See
[the publication record](../evidence/2026-10-11-shower-history-install.md#pi-131-publication).
Installation is separately confirmed by STARTUP_READINESS_INSTALLED: both history

were active on subsequent restricted readback.
