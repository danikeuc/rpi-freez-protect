# v1.3.0 - Shower history and companion controls

The Pi adds durable AUTO/manual shower transition history. The companion Dial
release adds its authenticated read-only admin view and includes the previously
operator-accepted admin redesign, shared Roon playlists/zones and QGSQ BLE work.

## Pi changes

- Record timestamp, operation, command and reason in the existing SQLite audit DB.
- Show startup, orderly shutdown, manual, AUTO, user stop and fault transitions.
- Deduplicate unchanged operation/command; keep rows over process restarts.
- Expose only bounded dedicated history records through the scoped GET endpoint
  and exact nginx route. Reads never invoke control/status or relay commands.
- Keep existing fail-closed audit-write handling. No historical backfill or
  automatic deletion. Abrupt power loss and failed storage can leave gaps.

See [history contract](../SHOWER_HISTORY.md) and the normal
[commissioning procedure](../../deployment/WORKSTATION_CODEX_COMMISSIONING.md).

## Compatibility and evidence

Paired GPIO protocol2 and P1 DRAIN retry remain unchanged. The Pi wheel does not
install the paired daemon or Node-RED flow. The history update uses the existing
weather-settings credential and needs the matching nginx route and Dial update.
No Synology update is needed beyond the already installed shared-playlist bridge.

Repository validation: 669 Pi tests, ruff, mypy and package build. Exact published
artifacts, hashes and device installation receipts are separate release evidence.
Companion offline suites cover history transport, auth/session fences, bounded
workers, UI pagination and existing admin behavior. Controller/GPIO state does not
prove physical valve position. No energized hydraulic or power-loss test is claimed.

The known intermittent BLE reconnect problem is not declared permanently fixed;
a same-firmware restart previously restored the connection and the operator
confirmed BLE plus shared playlists. No new BLE fix is part of shower history.

Existing release tags are preserved. This release does not enable AUTO, clear
USER_OFF, authorize SUPPLY, or reconnect 24 V valve power.

Companion tag: `danikeuc/roon-knob:v1.3.0-shower.3`; historical `v1.3.0` is preserved.
The trusted-console updater in `deployment/shower-history` preserves the deployed
source checkout and records installed wheel source/hash separately. Independent
review closed stop-request cleanup, immediate HTTP rejection and backup parent
fsync findings.
